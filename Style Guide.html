Peachy Pop

Cozy, warm, candy-soft. Everything is rounded, everything has a glossy top and a soft bottom shadow — like pressable sweets. Never pure black, never pure gray.

Color

Warm surfaces, one coral accent, five panel colors. Ink is a warm brown — use it everywhere you'd reach for black.

Panels

The core unit. Radius = 30% of size. Gradient top→bottom of the color pair, glossy highlight strip, hard bottom edge in the dark shade, and a white ~42% glyph per color for color-blind readability.

Berry → heartMint → ring · Sky → diamond · Honey → star · Plum → triangle
Popping statefill flips to white + colored outer glow, glyph hidden
Rising row45% opacity + saturate(0.7) until it locks in
Grid48px cells, 6px gap on the main board · mini board 12px/2px

Buttons & chrome

Candy buttons: gradient fill, glossy inset top, dark hard bottom edge (the "pressable" look). Chrome buttons are translucent white circles.

Hint pill · caramel text ×4 CHAIN!

Radii & shadow recipe

Panels 30% of size · cards 20px · board frame 30px · buttons/pills full round

Every raised element =
inset 0 2-3px 0 rgba(255,255,255,.5) gloss
inset 0 -4px 0 rgba(0,0,0,.1) underside
0 Npx 0 [darker shade] hard edge
0 N·2px N·3px rgba(110,86,72,.18) warm drop shadow — shadows are always warm brown, never black.

Rules of thumb

· Backgrounds: cream→peach vertical gradients, radial white glow at top
· Max 1 coral accent element per view (Play button / score)
· Decorate with tilted panels (±8–16°) and 4-point sparkles, sparingly
· Text on white/cream: Ink #6E5648; labels caramel #C99B82
· Danger = dashed rgba(240,96,108,.35) line, never solid red
· No pure black, no pure gray, no sharp corners
